# StreamScout webOS
Separate TV client repository; backend lives in gantou/streamscout. No root privileges, shell execution, credential collection or DRM bypass. Launcher connects only to a user-configured trusted server. Hosted UI is top-level, never framed (backend CSP blocks framing). webOSUserScripts adapts the server page without changing the backend repository. Preserve the TV screensaver defaults. Test launcher, remote mapping, package contents and actual server health; physical TV playback remains unverified until exercised on-device. Commit/push verified batches. Do not publish this private project publicly without user approval.
